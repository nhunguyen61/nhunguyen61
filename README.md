## 📊 Featured project

### [Which Asian markets should an Australian metals exporter prioritise?](https://github.com/nhunguyen61/australian-metals-market-prioritisation)
*Python · Power BI · ABS trade data*

Market-prioritisation analysis of Australian non-ferrous metal exports across 8 Asian markets, using 138 months of ABS data (2015–2026).

- Identified **Vietnam** as the top growth opportunity: **33.2% 3-year CAGR**, low volatility, and a SARIMA model that beat naive benchmarks (**MAPE 14.13%**)
- Showed that the current largest market (**Malaysia, AUD 2.17bn**) is not where the momentum is, and flagged China's **30.7% recovery** from its recent trough
- Built a 3-page Power BI decision dashboard with out-of-sample validation and simulated forecast intervals
